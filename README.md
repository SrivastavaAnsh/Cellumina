# Cellumina
### Explore Cells. Discover Life.

Cellumina is an interactive iPad educational app that makes cellular biology engaging through hands-on exploration, simulations, and AI-powered explanations. Instead of relying on static textbook diagrams, students can explore cell structures, interact with a living amoeba, and discover how cells communicate.

## ✨ Features

### 🔬 Cell Explorer
- Explore animal, plant, and bacterial cells through interactive visual representations.
- Tap on organelles to learn about their structures and functions.
- Understand complex cellular concepts through interactive exploration.

### 🦠 Amoeba Simulator
- Interact with a living amoeba in a dynamic environment.
- Move the amoeba and eat bacteria.
- Monitor energy and water levels through an interactive HUD.
- Learn biological concepts through simulation and experimentation.

### 🧫 Cell Network
Explore how cells communicate through three signaling mechanisms:
- **Autocrine:** Cells signal to themselves.
- **Paracrine:** Cells communicate with nearby cells.
- **Endocrine:** Signals travel to distant target cells.

### 🤖 AI-Powered Learning
- Integrates Apple's Foundation Models framework to generate simplified explanations and summaries.
- Makes complex biological concepts easier to understand.
- Includes text-to-speech functionality to support accessible learning.

## 🛠️ Built With

- **Swift** — Core application logic
- **SwiftUI** — User interface and navigation
- **SpriteKit** — Interactive simulations and animations
- **Foundation Models** — On-device AI-powered educational explanations
- **AVFoundation** — Text-to-speech functionality

## 🎯 Target Audience

Designed for students in **Classes 9–12**, Cellumina helps make cellular biology easier to understand through interactive learning.

## 🚀 Getting Started

### Requirements
- macOS with a compatible version of Xcode
- An iPad simulator or compatible physical iPad
- An iPadOS version supported by the project

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/SrivastavaAnsh/Cellumina.git
   ```

2. Open the project in Xcode.
3. Select a compatible iPad simulator or physical device.
4. Build and run the application.

**Note:** Foundation Models features require compatible Apple hardware and supported operating-system versions. Check the project settings for the exact deployment requirements.
